# Discovery Web Piscine

## Project Overview

This project is a practical introduction to Linux terminal navigation, file manipulation, Git, and GitHub. The exercises focus on using terminal commands, organizing files and directories, automating simple file tasks with a shell script, and managing project versions with Git.

## Exercises

- **ex00:** Navigate directories and create a recursive directory listing.
- **ex01:** Create and manipulate files using a shell script.
- **ex02:** Initialize a Git repository, create a commit, connect it to GitHub, and push it.
- **ex03:** Document the project and practice the complete Git workflow.

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes made to a project. If something goes wrong, earlier versions can be reviewed or restored instead of losing the work.

Version control also helps protect code by recording each committed change and its message. This makes it easier to understand what changed and when it changed.

Git is also useful for teamwork. Developers can share the same project through a remote repository such as GitHub, work on changes, and keep the project history organized for everyone.
